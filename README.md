# Ekips Prime Pro – VS Code Extension

VS Code support for the
[Ekips Prime Pro](https://github.com/Ekips-Prime-Pro/Ekips-Prime-Pro-Core)
robot language (`.ekips` files).

> **Status:** not started yet.

## Plan

1. Syntax highlighting
2. Errors, autocomplete and hover docs via the language server from
   Ekips-Prime-Pro-Tools
3. Buttons for "Simulate" and "Upload to hub"
4. Language reference for Copilot and other AI assistants
